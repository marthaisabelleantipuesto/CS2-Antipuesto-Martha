# Electricity Bill Calculator

## Description
This program calculates the total electricity bill.

## How to Run
1. Open 'electricity_calculator (3).py'
2. Run the program.
3. Enter the required inputs.

## Version 1 – Original code without input validation
- Input: Accepts a user's name and the previous and current meter reading's.
- Process: Calculates and displays the total bill.
- Output: Total bill, customer's names, and electricity consumption.
- Includes input validation.
